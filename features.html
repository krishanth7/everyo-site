Start with a tensor.

  • Reshape, transpose, stack, and concatenate

02 / FOLLOW THE GRAPH

A backward pass.
A forward understanding.

Reverse-mode differentiation records operations and accumulates gradients through an iterative topological traversal.

Use requires_grad=True to start recording. Use eo.no_grad() for inference without building a gradient graph.

05 / TRUST COMES WITH CONTEXT

Clear capabilities.
Explicit limits.

EveryO is built for learning, teaching, and small-scale experiments. It is not a production training runtime.

Component What to expect Evidence & limits
CPU / NumPy The standard local workflow Finite-difference gradient checks and project tests
TensorFlow Optional numerical reference Install separately for reference comparisons
CUDA Optional native kernels with CPU fallback Project CI has no GPU runtime validation. The standard Tensor path uses host buffers; the separate resident-buffer API is tested with a CPU stand-in
ONNX Export supported graphs Optional extra; validate unsupported operations and target runtime
Distributed CPU process-level training; experimental TCP process groups Multi-machine training has not been validated
Mixed precision autocast and GradScaler Autocast applies to matmul and conv2d
