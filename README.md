# EveryO — public website

The static public website for [EveryO](https://github.com/krishanth7/EveryO), a NumPy-based neural computing framework for learning, teaching, and small-scale experiments.

**Website:** https://krishanth7.github.io/everyo-site/

## Structure

- `index.html`: product overview, gradient example, capabilities, measured results, installation, verification limits, and project policies.
- `everyo-corporate.css`: responsive layouts and light/dark theme tokens. System sans-serif typography for prose, system monospace for code.
- `everyo-corporate.js`: theme preference and accessible mobile navigation. No external scripts, analytics, or cookies.
- `assets/img/`: figures generated by the framework examples.

## Local development

No build step or package manager is required. Run `python3 -m http.server 8000` from the repository root, then open http://localhost:8000.

## Appearance and navigation

The header links to the overview, framework, validation, documentation, and community. A right-side theme button follows the system preference until a visitor chooses a theme. The choice is remembered locally and applied before the first paint. Storage failures are handled gracefully.

Navigation collapses below 1101px. Closed mobile links are hidden and inert; Escape closes the menu and restores focus. Links remain available if JavaScript is disabled.

## Content maintenance

Use the framework README and documentation as the source for capabilities and limits. Test totals depend on optional dependencies and hardware, so the landing page links to current CI results rather than advertising a fixed count. Numerical results elsewhere on the page are example-run measurements, not performance guarantees. Keep GPU and multi-machine validation limits explicit.

## Deployment

GitHub Pages serves the root of `main`; `.nojekyll` preserves the static files. Keep the existing Pages settings. No alternate hosting configuration is required.
