05 / DIRECT ANSWERS

Good questions.
Clear starting points.

The essentials before your first experiment.

What is EveryO?

EveryO is an open-source Python neural computing framework built from scratch on NumPy. It implements tensors, automatic differentiation, neural networks, optimizers, and training for learning, teaching, and small-scale experiments.

Who should use EveryO?

EveryO is for developers learning neural-network internals, educators teaching numerical computing, and experimenters who want readable implementations and small, reproducible CPU workflows.

Why use EveryO if I already use PyTorch or JAX?

Use EveryO as a learning companion when you want to trace how gradients, layers, and parameter updates are implemented. Keep using your established framework for large-scale training, optimized accelerator execution, or its broader model ecosystem.

What can I build with EveryO?

You can build small classifiers, regression models, convolutional networks, recurrent networks, and transformer experiments. The repository includes runnable examples with locally generated datasets, visualization, and model saving.

What do I gain while using EveryO?

You can connect mathematical concepts to readable Python, inspect intermediate tensors and gradients, compare numerical results, and modify small experiments. Those workflows help you understand why a model behaves as it does.

Do I need a GPU, an account, or an API key?

No GPU, account, or API key is required for the core NumPy CPU workflow. Install the Python dependencies first; the bundled datasets are generated locally. CUDA, TensorFlow reference checks, and ONNX export are optional integrations.

Is EveryO suitable for production or large-scale training?

EveryO is designed for learning, teaching, and small-scale experimentation. It is not a production training runtime. GPU runtime behavior needs hardware validation, multi-machine training remains unverified, and supported ONNX exports must be checked with the target runtime.
