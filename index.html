    WHAT IS EVERYO?

    Explore the foundations of intelligent computing.

    EveryO is a neural computing framework written from scratch in Python on NumPy. Follow a number from a tensor, through an operation, and into its gradient.

    Built for learning, teaching, and small-scale experiments, it brings tensors, automatic differentiation, layers, optimizers, and training into one readable project.

    A learning and experimentation framework—not a production training runtime.

    Explore the architecture →

    READ. COPY. EXPERIMENT.

    See EveryO in action.

    Explore a practical example and discover how the framework brings computational concepts together.

    tensor_basics.py Python
    import everyo as eo

x = eo.tensor([[1.0, 2.0]])
y = eo.tensor([[3.0], [4.0]])

print(eo.matmul(x, y))

    EXPECTED OUTPUT · NOT EXECUTED HERE

    Tensor([[11.]], shape=(1, 1), dtype=float32)
    [1, 2] × [3, 4]ᵀ11

    Small tensors. Clear results.

    Matrix multiplication combines two tensors. This documented example produces a single value: 1 × 3 + 2 × 4 = 11.
