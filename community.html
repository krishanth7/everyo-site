02 / A GOOD BUG REPORT IS A CONTRIBUTION

Help us see
what you see.

Make issues easier to reproduce with a small example and enough context to understand the failure.

Open a bug report
  1. 01

    Show the environment

    EveryO and Python versions, OS, hardware, and optional components.

  2. 02

    Reduce the example

    The smallest code sample that demonstrates expected and actual behavior.

  3. 03

    Include the evidence

    Complete error text and commands attempted. Remove secrets and personal paths.
