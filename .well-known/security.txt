# In scope

#
# Notes for researchers
#   The library makes no network calls, stores no credentials and loads models
#   without pickle, so the usual deserialisation and SSRF classes should not
#   apply. If you find one anyway, that is exactly the report worth sending.
#
#   This site is static, has no backend, no cookies and no third-party
#   scripts. Please do not report missing security headers that GitHub Pages
#   controls and the project cannot set.
