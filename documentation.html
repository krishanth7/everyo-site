    01 / INSTALLATION

    Your first local experiment.

    Use Python 3.9–3.12 in an isolated environment. Clone EveryO and create a virtual environment:

    git clone https://github.com/krishanth7/EveryO.git
cd EveryO
python -m venv .venv
    Activate on Linux or macOS
    source .venv/bin/activate
    Activate on Windows PowerShell
    .venv\Scripts\Activate.ps1

    Install and check

    python -m pip install -e .
everyo info
everyo doctor
everyo demo

    doctor performs a core gradient check and reports optional components. demo trains the bundled digit classifier locally.

    Installing dependencies may require a network connection. Core experiments run locally without accounts, API keys, or telemetry.
