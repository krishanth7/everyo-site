01 / LOCAL-FIRST SETUP

Install from source.

Use Python 3.9–3.12 for the documented CPU workflow. The core dependencies are NumPy and Matplotlib. Installation downloads dependencies; core experiments can then run locally without accounts, API keys, or telemetry.

Terminal · Linux / macOS 
git clone https://github.com/krishanth7/EveryO.git
cd EveryO
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
everyo doctor
everyo demo
Using Windows PowerShell?

Create the environment with python -m venv .venv, then activate it with:

PowerShell 
.venv\Scripts\Activate.ps1

Continue with python -m pip install -e . and the doctor command above.

Check the installation.

everyo doctor performs a real gradient check and reports optional components. everyo demo trains a digit classifier end to end.

Optional integrations
Terminal 
python -m pip install -e ".[onnx]"
# Or install the TensorFlow reference backend:
python -m pip install -e ".[tensorflow]"

CUDA has a separate native build. Follow the CUDA guide; a CUDA extra alone does not provide a working extension.

02 / COMPUTE A GRADIENT

Meet your autograd engine.

EveryO records the multiplication because x requires gradients. The backward pass fills x.grad with [4.]: the derivative of x² at x = 2.

first_gradient.py 
import everyo as eo

x = eo.tensor([2.0], requires_grad=True)
y = x * x
y.backward()

print(x.grad)  # [4.]
Understand graph traversal and accumulation

03 / COMPOSE LAYERS

A network you can inspect.

Connect a four-feature input to a three-class output with a hidden layer and ReLU activation. This model has 131 trainable parameters.

first_network.py 
import everyo as eo

model = eo.Sequential(
    eo.Linear(4, 16, seed=0),
    eo.ReLU(),
    eo.Linear(16, 3, seed=1),
)

print(model.num_parameters())  # 131
Keep the output as logits.

CrossEntropyLoss applies log-softmax internally. End your classifier with a plain Linear layer.

04 / A COMPLETE EXPERIMENT

Generate data. Train. Evaluate.

This self-contained example creates a seeded dataset, holds out 20% for evaluation, and trains with Adam. Run it after installing EveryO.

train_classifier.py 
import everyo as eo
from everyo.datasets import make_blobs

features, labels = make_blobs(
    n_samples=600, n_features=4, centers=3, seed=0
)
x_train, x_test, y_train, y_test = eo.stratified_split(
    features, labels, test_size=0.2, seed=0
)
model = eo.Sequential(
    eo.Linear(4, 16, seed=0), eo.ReLU(),
    eo.Linear(16, 3, seed=1),
)
trainer = eo.Trainer(
    model, eo.Adam(model.parameters(), lr=0.01),
    eo.CrossEntropyLoss(), metrics=["accuracy"],
)
train_loader = eo.DataLoader(
    eo.ArrayDataset(x_train, y_train),
    batch_size=32, shuffle=True, seed=0,
)
test_loader = eo.DataLoader(
    eo.ArrayDataset(x_test, y_test), batch_size=64,
)
history = trainer.fit(
    train_loader, epochs=20, validation_loader=test_loader
)
print(trainer.evaluate(test_loader))

Accuracy depends on the generated data and training run. Inspect the returned evaluation metrics rather than assuming a fixed result.

05 / KEEP THESE CLOSE

The essential API.

eo.tensor(data, ...)

Create a tensor. Set requires_grad=True to record operations.

Tensor.backward()

Differentiate a scalar result and accumulate gradients.

eo.Sequential(*layers)

Compose layers into a feed-forward model.

eo.Linear(in_features, out_features)

An affine layer with optional bias, initializer, and seed.

eo.Adam(parameters, lr=...)

Adaptive optimization with per-parameter state.

eo.Trainer(model, optimizer, loss_fn)

Train, evaluate, and predict with callbacks and history.

eo.save(model, path)

Write a pickle-free .evo archive.

eo.load(path)

Rebuild a supported model and restore its parameters.
