    EVERYO / EXAMPLES

    Examples you can follow

    Read a small example here, then open the corresponding Python scripts to experiment locally.

    tensor_basics.py Python
    import everyo as eo

x = eo.tensor([[1.0, 2.0]])
y = eo.tensor([[3.0], [4.0]])

print(eo.matmul(x, y))

    EXPECTED OUTPUT · NOT EXECUTED HERE

    Tensor([[11.]], shape=(1, 1), dtype=float32)
    [1, 2] × [3, 4]ᵀ11

    Small tensors. Clear results.

    Matrix multiplication combines two tensors. This documented example produces a single value: 1 × 3 + 2 × 4 = 11.

    These are documented or analytically derived outputs. Python does not run in this page.
