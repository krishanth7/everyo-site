RUN LOCALLY / VERSIONED COMMANDS

Set up once. Run real scripts.

The example links open the Python source on GitHub. The copy buttons copy terminal commands; this website does not execute Python in your browser. First clone EveryO and install the v0.5.0 release below. Run each example from the repository root.

macOS / Linux · first-time setup

Terminal · bash or zsh
git clone https://github.com/krishanth7/EveryO.git
cd EveryO
git checkout v0.5.0
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m pip check
everyo doctor

Windows · first-time setup

Terminal · Windows PowerShell
git clone https://github.com/krishanth7/EveryO.git
cd EveryO
git checkout v0.5.0
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m pip check
everyo doctor

Each setup block is a sequence of terminal commands. If PowerShell prevents script activation, use .venv\Scripts\python.exe to invoke Python directly, or consult the troubleshooting guide. The default examples require Python, Git and access to install dependencies; no GPU is needed for the CPU core.
